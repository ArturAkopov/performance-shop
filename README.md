# Нагрузочное тестирование Performance Shop

**Платформа обучения:** [QA.GURU](https://qa.guru)  
**Тип проекта:** Итоговая аттестационная работа по курсу «Инженер по тестированию производительности»

---

## О проекте

Проект посвящён нагрузочному тестированию микросервисного приложения **Performance Shop** — интернет-магазина на FastAPI
с базой данных PostgreSQL, развёрнутого через Docker Compose.

**Основная цель:** подтвердить или опровергнуть наличие 3-кратного запаса производительности системы относительно
пикового часа нагрузки.

---

## Тестируемая система

| Компонент         | Описание                          |
|-------------------|-----------------------------------|
| **Приложение**    | FastAPI (Python 3.11), 3 инстанса |
| **База данных**   | PostgreSQL 15                     |
| **Балансировщик** | Nginx                             |
| **Мониторинг**    | Telegraf → Prometheus → Grafana   |
| **Запуск**        | Docker Compose                    |

---

## Ключевые показатели

| Параметр                   | Целевое значение            |
|----------------------------|-----------------------------|
| **Уровни нагрузки**        | 1x, 2x, 3x от пикового часа |
| **Длительность тестов**    | 2 часа (стабильность)       |
| **CPU (каждый контейнер)** | < 90%                       |
| **RAM (каждый контейнер)** | < 80%                       |
| **Доля ошибок**            | < 1%                        |
| **SLO**                    | По 95-му перцентилю         |

## Структура репозитория

```
.
├── app/                 # Приложение и конфигурационные файлы
├── documentation/       # Методика нагрузочного тестирования
├── scripts/             # Скрипты JMeter и тестовые данные
└── results/             # Результаты прогонов и отчёты
```

---

## Быстрый старт

### Запуск приложения

```bash
cd app
docker-compose up -d
curl http://localhost/api/health
```

### Запуск нагрузочных тестов

```bash
jmeter -n -t scripts/performance_shop.jmx -l results/logs/run.jtl -e -o results/reports/dashboard
```

### Мониторинг

```bash
# Проверка метрик Telegraf
curl http://localhost:9273/metrics | grep docker_container

# Просмотр ресурсов контейнеров
docker stats
```
